# Interactive Portfolio Theory

An interactive web application demonstrating key concepts in Modern Portfolio Theory, including the efficient frontier, optimal portfolio selection, and the Capital Market Line (CML).

## 🌐 Live Demo

Visit the live application at: **[https://sakibanwar.github.io/Portfolio-Theory/](https://sakibanwar.github.io/Portfolio-Theory/)**

## 📊 Features

- **Interactive Visualizations**: Real-time plots powered by Plotly.js
- **Adjustable Risk Aversion**: Use the slider to change the investor's risk aversion parameter (γ) and see how it affects optimal portfolio selection
- **Two Scenarios**:
  - **Plot 1**: Optimal choice in a risky-assets-only world (efficient frontier)
  - **Plot 2**: Optimal choice with a risk-free asset (Capital Market Line)

## 🎓 Educational Concepts

This tool helps visualize:
- The **Efficient Frontier**: The set of optimal portfolios offering the highest expected return for a defined level of risk
- **Indifference Curves**: Representing investor preferences based on risk aversion
- **Tangency Portfolio**: The optimal risky portfolio when a risk-free asset is available
- **Capital Market Line (CML)**: The line representing optimal risk-return combinations when mixing the tangency portfolio with the risk-free asset

## 🚀 Usage

Simply open the application in your web browser and adjust the risk aversion slider (γ) to see how different investor preferences lead to different optimal portfolio choices.

## 🛠️ Technical Details

- Pure HTML/JavaScript application
- Uses [Plotly.js](https://plotly.com/javascript/) for interactive visualizations
- Styled with [Tailwind CSS](https://tailwindcss.com/)
- No backend required - runs entirely in the browser
